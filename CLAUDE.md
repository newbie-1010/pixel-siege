# Pixel Siege

A retro top-down shooter for the browser. The player moves with the arrow keys or WASD, aims with the mouse, and clicks or holds to shoot. There are 6 levels, ending in a boss fight. Plain HTML5 canvas and JavaScript: no libraries, no build step, no assets on disk.

## Running

Open `index.html` in a browser (double-click works). Everything works offline.

## Files

Scripts are classic `<script>` tags, not ES modules, so the game runs from `file://`. They share globals and must load in the order listed in `index.html`:

1. `js/config.js`: `W`/`H` (320x180 internal resolution), `HUD_H`, `ARENA` walk bounds, `GUN_Y`, and the helpers `clamp`, `rand` and `pick`.
2. `js/sprites.js`: all pixel art as character grids plus palettes, `buildSprite`/`makeFrame` (each frame also gets a white copy for hit flashes), `drawSprite`, `drawShadow`, and the 5x5 pixel font (`FONT`, `drawText`, `textWidth`). Sprites live on the global `SPR`.
3. `js/audio.js`: `SFX`, with sound effects generated by Web Audio. `SFX.play(name)`; `init()` runs on the first input because browsers block audio until then.
4. `js/input.js`: `Input`. `down(...codes)` means held; `hit(...codes)` means pressed this step. Also `mx`/`my` (mouse in game pixels), `mouseDown`, `clicked` and `moved`.
5. `js/levels.js`: the `LEVELS` table (kill target, spawn interval, max alive, speed multiplier, enemy mix, `boss`) and `buildArena(theme, seed)`, which paints each level's floor with a seeded random generator.
6. `js/entities.js`: `ENEMY_DEFS` (enemy stats), `Player`, `Enemy` (AI per type in `update`), `Bullet`, `Particle`, `Popup` and `Pickup`.
7. `js/game.js`: the canvas and integer scaling, `Save` (localStorage), the `G` state object, level flow, spawning, combat and collisions, the screens and HUD, and the fixed 60 Hz loop.

## Game flow

- **States:** `MENU → INTRO → PLAYING → CLEAR → INTRO (next level) … → VICTORY`.
  - `PLAYING` can switch to `PAUSED`.
  - `PLAYING` ends in `GAMEOVER` when the player dies. From there, Retry restarts the level at the score the level started with.
- **Normal levels:** spawn up to `kills` enemies just outside a random edge. The level clears when `G.kills >= def.kills`.
- **Boss level:** spawns the Warlord. Its minions don't count toward kills. The level clears when `G.boss.dead`.
- **Between levels:** the player is restored to full HP each level. Leftover hearts give a bonus of 50 points each.
- **Saving:** `Save.data` holds `hi`, `maxLevel` (used for the menu's Continue option) and `muted`, under the localStorage key `pixelSiege.v1`.

## Enemies

| Type | Behavior |
|---|---|
| slime | Hops toward the player |
| bat | Fast and weaves side to side |
| skeleton | Keeps about 80 px away, strafes, fires aimed shots |
| brute | Charges after a 0.6 s shaking, flashing wind-up |
| boss | 140 HP; cycles a ring, an aimed fan and a fast ring of bullets; spawns bats and slimes; faster below half HP |

## Making changes

- **New enemy:** add its stats to `ENEMY_DEFS`, add frames to `SPR.<type>`, add a `case` in `Enemy.update`, add colors to `DEATH_COLORS` in `game.js`, and give it a weight in a level's `mix`.
- **New level:** add a row to `LEVELS`. To give it a new floor, add an entry to `THEMES` and a branch in `buildArena`.
- **Sprites:** each character in a grid maps to a color in that sprite's palette. `.` and any character missing from the palette are transparent. Keep every row the same width.
- **Text:** `drawText` only renders characters defined in `FONT` (A–Z, 0–9 and `: / ! - . + > < , ? '`). Add a glyph before using a new character.
- **Coordinates:** everything is in 320x180 game pixels. Round positions when drawing to keep pixels crisp.
