# Pixel Siege

A retro top-down pixel-art shooter for the browser, **developed by [newbie-1010](https://github.com/newbie-1010)**.

**Play it:** [itch.io](https://newbie-1010.itch.io/pixel-siege) · [GitHub Pages](https://newbie-1010.github.io/pixel-siege/)

Fight through 6 levels of slimes, bats, skeletons and brutes, then take on the Warlord. The game runs on plain HTML5 canvas and JavaScript, with no downloads and no plugins.

## Controls

| Action | Input |
|---|---|
| Move | Arrow keys or WASD |
| Aim | Mouse |
| Shoot | Click or hold left mouse button |
| Pause | P or Esc |
| Sound on/off | M |

You need a keyboard and mouse to play, so it won't work on phones or tablets.

## Enemies

- **Slime:** hops toward you.
- **Bat:** fast, and weaves from side to side.
- **Skeleton:** keeps its distance and fires aimed shots.
- **Brute:** winds up, then charges.
- **The Warlord:** the final boss. It fires bullet rings and fans and calls in minions.

Your high score and furthest level are saved in your browser.

## Running locally

Clone the repo and open `index.html`. You don't need to build or install anything.
